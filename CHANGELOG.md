## [v0.1.0] - 2026-06-15

### Highlights

- Initial release of OpenRouter thick provider for OmniLLM
- Access to 300+ AI models through unified omnillm interface

### Added

- [omnillm] OpenRouter provider implementing `core.Provider` interface
- [omnillm] Streaming support via `CreateChatCompletionStream`
- [omnillm] Tool/function calling support
- [omnillm] JSON mode support
- [auth] OAuth PKCE authentication flow for interactive login
- [auth] API key storage in system keyring via omnivault

### Dependencies

- `github.com/OpenRouterTeam/go-sdk` v0.5.0
- `github.com/plexusone/omnillm-core` v0.17.0
- `github.com/plexusone/omnivault` v0.5.0
